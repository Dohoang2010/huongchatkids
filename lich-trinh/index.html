Chưa kết nối máy chủ

Ứng dụng cần máy chủ Google Apps Script để lưu lịch và gửi tin nhắn.

  1. Tạo Google Sheet mới tên “Lịch làm việc”.
  2. Tiện ích mở rộng → Apps Script → dán code từ tools/lich-trinh-apps-script.gs.
  3. Triển khai → Ứng dụng web (Thực thi: Tôi · Truy cập: Bất kỳ ai).
  4. Dán link /exec vào lich-trinh/config.js.
